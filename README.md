# Perkins

Web-based salary management software for an HR manager overseeing
10,000 employees across multiple countries — replacing spreadsheets
with a searchable directory, salary history, aggregate reporting, and
natural-language Q&A over pay data.

Named after Frances Perkins, architect of U.S. minimum-wage and labor
law.
